# Primeira Versão dos Sites 🌐

Repositório criado durante as aulas de **Desenvolvimento Front-end para Web**, reunindo os sites e exercícios práticos desenvolvidos em sala de aula.

## 📁 Estrutura do Projeto

```
├── exemplo-css/       # Exemplos práticos de estilização com CSS
├── forms/             # Exercícios de formulários HTML (inputs, selects, botões etc.)
├── imagens/           # Imagens utilizadas nos projetos e exercícios
├── medalhas/          # Projeto/exercício específico envolvendo "medalhas"
├── pratica-css/       # Prática de CSS: Site de Ingressos com vídeo de fundo
├── venda-ingressos/   # Projeto de página para venda de ingressos
├── README.md          # Documentação do repositório
├── camera.jpg         # Imagem de capa (poster) exibida caso o vídeo não carregue
├── index.html         # Página inicial do repositório
├── logo.jpg           # Logotipo utilizado no(s) site(s)
├── semantica.html     # Exercício sobre HTML semântico
└── video.mp4          # Vídeo utilizado no Site de Ingressos (pratica-css)
```

## 🎯 Objetivo

Este repositório tem como finalidade documentar a evolução do aprendizado em desenvolvimento front-end, abordando conceitos como:

- Estruturação de páginas com **HTML** (incluindo **HTML semântico**)
- Estilização com **CSS**
- Criação e manipulação de **formulários**
- Inserção e configuração de **mídias** (vídeo e imagens)
- Boas práticas de organização de arquivos e pastas em um projeto web

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

## 📌 Observações

- Cada pasta representa um exercício ou etapa diferente do aprendizado, feito em sala de aula.
- Os arquivos `index.html` e `semantica.html` na raiz do projeto servem como pontos de entrada/exemplo geral.
- Este é um repositório em constante atualização, conforme novas aulas e exercícios forem realizados.
